# Archive: earlier phase (ARLHNIDS re-evaluation and OnePass-IDS)

The project started as a leak-free re-evaluation of ARLHNIDS-IoT and a small one-pass IDS. Its README, results index,
figures, run scripts and saved results are kept here unchanged (`git mv`, history intact). The dated tests are in
`../PREREG.md`. The code is still in `../scripts/` (see `../scripts/README.md`); those scripts write to
`results/<name>/`, and their saved outputs from that phase are in `archive/results/<name>/`.
